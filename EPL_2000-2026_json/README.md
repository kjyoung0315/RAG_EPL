# EPL 2000–2026 PFA 베스트11 보완 완료

- 2000–01부터 2025–26까지 총 26개 시즌의 PFA Premier League Team of the Year를 시즌당 정확히 11명씩 저장함 (286개의 선수-시즌 JSON).
- 이번에 보완된 23개 시즌(2001–02~2023–24): 253명의 선수-시즌 JSON과 23개의 시즌별 통합 JSON 새로 추가.
- 각 JSON에 당시 구단, 포지션 범주(GK/DF/MF/FW), 시즌, Wikipedia 출처를 기록함. 과거 동일 선수가 여러 시즌 선정된 경우 시즌별로 별도 파일 유지.
- 앞선 ZIP의 기존 구단/성적/한국 선수 데이터를 유지함. **기존 성적 및 한국 선수의 수치는 이 업데이트에서 재검증하지 않았음.** 따라서 이번의 베스트11 검증을 기존 전체 데이터 검증으로 확대 해석하지 말 것.
- 2026–27 시즌은 진행 중이므로 선정팀이 없음.
