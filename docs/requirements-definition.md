# EPL Insight RAG 요구사항 정의서

## 1. 도메인 및 데이터 범위

- **도메인:** 잉글랜드 프리미어리그(EPL) 기록 기반 지식 서비스
- **범위:** 2000-01~2025-26 완료 시즌 및 2026-27 수집 시점 기준 스냅샷
- **항목 메타데이터:** `EPL_2000-2026_json`의 JSON 817개를 읽어 중복을 제거한 691개 팀·선수·시즌·수상 항목
- **외부 문서:** 한국어 위키백과 API. 문서 제목, 원문 URL, 검색어, 수집 시점을 보관한다.
- **위험 도메인 여부:** 스포츠 기록·정보 도메인이므로 의료·금융 면책 문구는 적용 대상이 아니다.

근거가 필요한 질문 예시는 다음과 같다.

1. 2003-04 아스널이 무패 우승을 했는지와 당시 성적은 무엇인가?
2. 손흥민이 2021-22 시즌 EPL 득점왕이 된 기록은 무엇인가?
3. 2015-16 레스터 시티의 우승이 특별하게 평가되는 배경은 무엇인가?

## 3. 비기능 요구사항

- API 키는 `.env`의 `GMS_KEY`로만 관리하며 화면이나 로그에 출력하지 않는다.
- JSON 수집·색인, 외부 수집, 검색, 생성, UI를 모듈로 분리한다.
- 위키백과 호출은 `WIKI_CONTACT` User-Agent와 분당 호출 제한을 적용한다.
- 검색어별 수집 결과와 문서 선별 이력을 캐시해 불필요한 재호출을 막는다.
- 로컬 데이터와 외부 문서의 URL·출처명을 근거 메타데이터에 남긴다.
